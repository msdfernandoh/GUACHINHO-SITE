# Hotfix 285 — Versão resumida com arquivos independentes

## Correção

O seletor de **Arquivos independentes** removia e desabilitava a opção de
versão resumida. A interface passa a manter essa escolha em todos os modos.

## Regra final

- Unificar + resumida: um resumo consolidado.
- Separar por grupo + resumida: uma proposta única resumida.
- Arquivos independentes + resumida: um PDF resumido para cada grupo.

Nos arquivos independentes, cada documento é montado com apenas o seu grupo;
por isso a versão resumida não combina prazo, taxa, reajuste ou parcela de
grupos diferentes.
